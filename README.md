# My blog

A minimal text blog published free with GitHub Pages.

To add a post: open the `_posts` folder, choose Add file > Create new file,
name it `YYYY-MM-DD-short-title.md`, paste the contents of `post-template.md`,
write, and press Commit changes. The site updates in about a minute.

To add a picture: open `assets/images`, choose Add file > Upload files,
then write `![description](/assets/images/file-name.jpg)` in the post.
